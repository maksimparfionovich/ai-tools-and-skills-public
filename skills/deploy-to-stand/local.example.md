# Факты проекта для deploy-to-stand (пример)

Скопируйте в `local.md` рядом со `SKILL.md` и опишите свой проект. Файл в git не идёт.

## Доступ к кластеру стендов

- Поды стенда: `kubectl --context stands get pods -n <стенд>` (namespace = имя стенда).
- Статусов сборки из терминала не видно (`gh` не установлен) — смотреть поды.

## Особенности репозиториев

- `frontend`: в репозитории pre-push хук (husky) — без `--no-verify` пуш тега может упасть.
- `backend`: на `demo` катится только ручной правкой версии в gitops — это делает девопс.
- Сборка по тегу у `worker` двигает `:latest`; прод от этого не зависит (версия закреплена в gitops),
  но незакреплённые стенды подхватят.

## Когда правила CI снимались

`config.local.json` снят с default-веток 2026-01-15. Если скрипт пишет «CI в default-ветке
изменился» — перечитать workflow и обновить запись репозитория.
