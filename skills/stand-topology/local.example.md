# Карта окружений (пример)

Скопируйте в `local.md` рядом со `SKILL.md` и заполните своими данными. Файл в git не идёт.
У каждого факта — основание и дата: «проверено запросом 2026-10-04», «из gitops», «предположение».

## Уточнения к чеклисту

- Свои стенды: `qa1`, `qa2`. Остальные общие, прод — только с согласия.
- Второй домен того же контента — `example.org`: на стендах его нет, проверка — GET на проде.
- Сервис цен живёт только на `demo` и общий для всех стендов: правка его базы видна везде.

### Нюансы прода, на которых уже обжигались

- CDN кэширует 404 ~5 минут вопреки `no-cache`: после смены адреса страница ещё минуты отдаёт 404 —
  не дефект рендера (разбор от 2026-09-16).
- После каждой выкатки фронта у открытых вкладок 404 на старые чанки ~1 час — норма.
- Headless-браузер для фронта — краулер: счётчики не отправляются; для живых проверок — обычный UA.
